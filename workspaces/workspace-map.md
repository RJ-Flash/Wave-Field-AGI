# Global Workspace Map
Welcome to the AGI File System Root.

- **/workspaces/general**: Default area for unclassified reasoning or scratchpad thinking.
- **/workspaces/writing**: Used strictly for drafting textual output, notes, or blogging.
- **/workspaces/production**: Used strictly for executing technical actions, building components, and engineering software.

## Constraints
1. You must respect the designated environments. Only write technical code to production.
2. If saving a file, use proper semantic filenames (e.g., `feature-spec.md` instead of `out.txt`).
3. Always check local `context.md` inside your active folder before operating.
